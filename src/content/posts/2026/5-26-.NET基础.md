## 01-C# .NET是什么

C#是现代的，面向对象的类型安全型的语言，由微软开发在.NET平台上运行。

C#和.NET的关系，就像.NET是一个舞台，c#就是在这个舞台上表演一样。其概括特性如下：

| **特点**     | **简要说明**                                               |
| ------------ | ---------------------------------------------------------- |
| **面向对象** | 用类、对象、继承、多态等组织代码，适合中大型项目           |
| **类型安全** | 编译期会做类型检查，减少很多运行时错误                     |
| **现代语法** | 持续迭代：顶级语句、模式匹配、记录类型、异步等（C# 12~14） |
| **强类型**   | 变量必须有明确类型（如 int、string），便于维护和工具支持   |

.NET是免费，跨平台的开发和运行平台，c#代码会在.net上运行

其概括特点如下：

| **概念**        | **说明**                                                     |
| --------------- | ------------------------------------------------------------ |
| **.NET SDK**    | 开发工具包，包含编译器、运行时、模板等，用来写和运行 .NET 程序 |
| **.NET 运行时** | 负责在电脑上“跑”已编译的 .NET 程序，代码交予运行时运行       |
| **.NET 生态**   | 除 C# 外还有 F#、VB.NET；以及 ASP.NET Core、.NET MAUI、EF Core 等框架 |

## 02-安装与编译

> SDK是什么

**.NET SDK** 是用于开发 .NET 应用的工具包，通常包含：

## 04-使用顶级语句输出代码

这里需要输出`hello world`，感觉有点蠢但是必须要做。

> 顶级语句

顶级语句是c#9.0引入的概念，允许在文件顶层直接编写可执行代码，无需定义`namespace`,`class` 以及`Main`方法。

| **特性** | **说明**                           |
| -------- | ---------------------------------- |
| **简洁** | 代码更简洁，减少样板代码           |
| **易学** | 初学者更容易理解，无需先学类和方法 |
| **现代** | 符合现代 C# 的编程风格             |

顶级语句会在编译的时候将其转化为完整结构，例如一个`console.writeline("hello world")`会自动转为如下的结构：

```c#
using System;

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello, World!");
        }
    }
}
```

> 使用编译器运行

使用顶级语句输出`Hello World`很简单，在`Program.cs`中填写下面语句即可：

```
Console.WriteLine("Hello, World!");
Console.ReadKey(); // 暂停这个位置
```

- **Console**：.NET 提供的类，用于控制台输入输出操作

- **WriteLine**：方法，用于向控制台输出一行文本，并在结尾添加换行符

- **"Hello, World!"**：字符串字面量，要输出的文本内容

- **;**：语句结束符，表示语句结束

## 05-基于文件/项目的应用

基于文件的应用编写方式，就是创建一个.cs文件，然后在cmd中使用具体的运行代码。

基于项目的应用编写方式，就是使用VS来进行运行程序

| **特性**     | **基于文件的应用**           | **基于项目的应用**                          |
| ------------ | ---------------------------- | ------------------------------------------- |
| **文件结构** | 单个 `.cs` 文件              | 包含 `.csproj` 文件和多个 `.cs` 文件        |
| **创建方式** | 直接创建 `.cs` 文件          | 使用 `dotnet new` 或 Visual Studio 创建项目 |

| **版本要求** | C# 14 / .NET 10+             | 所有版本支持                                |

一般来说，基于文件的应用优势：

- **快速启动**：无需创建项目文件，直接编写代码即可运行

- **适合脚本**：可以像脚本一样快速执行 C# 代码

基于项目的应用的优势:

- **完整功能**：支持 NuGet 包管理、多文件组织、复杂配置
- **生产就绪**：适合实际项目开发
- **工具支持**：Visual Studio、Rider 等 IDE 提供完整支持
- **版本控制**：项目文件可以记录依赖和配置信息

## 06-传统写法

传统写法的结构：

```c#
using System; 

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello, World!");
        }
    }
}
```

对于这些结构做简要说明：

- using指令：引入命名空间
- namespace声明：定义命名空间
- class声明：定义类，通常为Program
- main方法：程序的入口

> 命名空间

namespace 规定一个空间，这里假设为A空间。任何没有引用A空间的程序，无法使用A空间中的代码内容。

命名空间的目的是为了防止不同空间的相同函数名称起冲突。引入命名空间的方法有两种

- 使用Using指令引入

```c#
using System; 

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello, World!"); // 方法在system命名空间中
        }
    }
}
```

- 使用完全限定名称引入

```c#
namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            System.Console.WriteLine("Hello, World!");
        }
    }
}
```

> 类

在传统写法中，代码都必须放置在类中

```c#
using System; 

namespace HelloWorld
{
	// 可运行代码都必须放在类中
    class Program
    {
		// 类的成员放在这里
    }
}
```

-  封装代码：组织相关代码
-  定义类型：类是C#代码的基本类型之一
-  程序入口：Main方法一般在Program类中

> Main方法

`Main` 方法是 C# 程序的**入口点 (entry point)**：

- 程序运行时，首先执行 `Main` 方法

* 每个可执行程序必须有且仅有一个 `Main` 方法

* `Main` 方法必须是 `static`（静态）的

`Main`的常见签名：

```c#
    class Program
    {
        static void Main()：无参数

        static void Main(string[] args)：带参数（接收命令行参数）

        static int Main()：返回 int（退出码）

        static int Main(string[] args)：带参数并返回退出码
    }
```

Main的要求：

1. 必须是`static`(静态方法)
2. 返回类型是`void`或者`int`
3. 方法名称必须是`Main`(区分大小写)
4. 参数(如果有)必须是string[]类型，参数名称通常是args

# 第二单元：语法和结构

## 08-注释

 c#中一般使用单行或者多行注释

```c#
// 这是单行注释

//* 
	这是多行注释
*//
```

一般来说使用注释需要注意以下要点：

| **用途**      | **说明**                               |
| ------------- | -------------------------------------- |
| 说明意图      | 解释“为什么”这样写，而不是重复“做什么” |
| 暂时禁用代码  | 调试时用 `//` 或 `/* */` 包住代码      |
| TODO / FIXME  | 标记待完成或待修复                     |
| 模块/方法说明 | 在文件头或方法上方写简短说明           |

在后天需要养成的书写习惯与原则

- **写“为什么”而不是“做什么”**：`i++;` 不必注释“i 加 1”，可注释“循环计数，用于控制输出行数”

- **避免过度注释**：代码能读懂的不必每行都注释；注释应与代码同步更新

- **保持简洁**：注释尽量简短清晰；过长说明可放在文档中

## 09-语句与代码块

语句（statement）是程序执行的基本单位，程序按顺序执行一条条语句。

- **声明语句**：如 `int a = 10;`

- **表达式语句**：如 `Console.WriteLine("Hi");`、`a++;`

- **控制流语句**：如 `if`、`for`、`return`

多数语句以分号 `;` 结束。

> 分号的作用

一个分号的出现标识着这个语句的结束，常用的有如下：

- **变量声明与赋值**：`int a = 10;`

- **方法调用作为语句**：`Console.WriteLine("Hello");`

- **赋值、自增等**：`x = 5;`、`i++;`

```c#
int x = 5;
console.writeline(x);
console.ReadKey();
```

> 代码块

代码块就是使用`{}`括起来的一条或者多条语句，一般用法如下：

* **方法体**：如 `static void Main() { ... }`

* **控制流**：`if`、`for` 等后面的多条语句放在一个块里

* **嵌套块**：块内可以再写块

```c#
{
	语句1;
	语句2;
}
```

> 语句与表达式

在执行内容上，**表达式用于“计算值”，而语句用于“执行操作”**。

- **表达式 (expression)**：会计算出一个值，如 `3 + 5`、`a * 2`、`Console.ReadLine()`

- **语句 (statement)**：执行操作的完整单位，如 `int a = 10;`、`Console.WriteLine("Hi");`

- **很多语句里会包含表达式**（如 `a = 3 + 5;` 中的 `3 + 5`）

- **仅执行表达式并丢弃结果时，称为表达式语句，同样以分号结束**

## 10.Using与命名空间

命名空间的作用是将不同的类和结构组合在一起，不同的命名空间内部的同名类型互不冲突

```c#
// 两个命名空间的相同名称方法互不冲突
namespace A{
	a();
	b()
}

namespace B{
	a();
	b();
}
```

在顶部使用`using`指令，表示本文件中可以使用system下的类型名称，不用写当前命名空间的前缀

```
using System;

Console.WriteLine("Hello");
string s = Console.Readline();
```

> 命名空间 与 函数 的关系

这里以`System` 和 `Console`举例，Console是位于System中的一个类

因此：完整的类型名为System.console，引入了Using system后，可只写Console

```c#
using System;

Console.WriteLine("Hello, World!");
Console.Write("请输入: ");
string input = Console.ReadLine();
```

如果不引入System,这种方式叫做完全限定名称，代码如下：

```c#
System.Console.WriteLine("Hello, World!");
System.Console.Write("请输入: ");
string input = System.Console.ReadLine();
```

> 声明与使用命名空间

可以在代码中自己创建命名空间。

“声明 namespace” 和 “using 引用命名空间” 是两件事：前者是 “我的代码放在哪个命名空间”，后者是 “我要使用哪些命名空间里的类型”。

## 11-标识符与命名规范 

**标识符**是程序员为变量、类、方法、命名空间等起的名字，如 `Program`、`userName`。

- 由字母、数字、下划线 `_` 组成

- 首字符不能是数字

- 不能与 C# 关键字完全相同（除非用 `@` 前缀）

**合法**：`name`、`userName`、`_count`、`MyClass`。

**不合法**：`2nd`（数字开头）、`class`（关键字）。C# 是大小写敏感的，`UserName` 与 `username` 是不同标识符。

> 标识符书写方法

PascalCase（帕斯卡），每个单词首字母大写，如 `Program`、`WriteLine`、`MyApp`。**用于**：类名、方法名、命名空间、属性、常量等。

camelCase（驼峰），首单词小写，后续单词首字母大写，如 `userName`、`countOfItems`。**用于**：局部变量、方法参数、私有字段等。

| **用途**           | **推荐风格** | **示例**               |
| ------------------ | ------------ | ---------------------- |
| 类、方法、命名空间 | PascalCase   | `Program`、`WriteLine` |
| 局部变量、参数     | camelCase    | `userName`、`count`    |

> 关键字

**关键字**是 C# 预留的、有特殊含义的单词，**不能**作为普通标识符使用。

常见关键字举例

* **类型**：`int`、`string`、`bool`、`void`、`class`

* **流程控制**：`if`、`else`、`for`、`while`、`return`

* **修饰与结构**：`public`、`static`、`namespace`、`using`

例如 `int class = 10;`、`string if = "hi";` 会报错，应改用合法标识符（如 `className`、`condition`）。

> @前缀

在特殊情况下（如对接 API 要求属性名为 `class`），可在标识符前加 `@`，使关键字被当作普通标识符使用，例如 `@class`、`@int`。

**建议**：仅在有充分理由时使用；一般优先改用语义相近的合法名称（如 `classId`、`returnValue`），可读性更好。

> 命名习惯

一般而言需要注意的命名习惯：

- **见名知意**：名称应能反映用途，避免无意义的 `a`、`b`（循环变量 `i`、`j` 除外）

- **与规范、团队一致**：遵循 PascalCase/camelCase 常规用法，团队有约定则保持一致

- **避免易混**：不要仅靠大小写区分两个标识符（如同时存在 `user` 与 `User`），避免过长或过短极端

# 第三单元：类型与变量

## 12-值类型与引用类型

在编程语言中，一切数据都有类型。

类型决定了一个数据应该使用多少内存，如何存储。能进行那些操作以及与其它类型之间的转换关系。

例如：`42` 是 `int` 类型，`"Hello"` 是 `string` 类型，`true` 是 `bool` 类型。

声明变量时要指定类型（或使用 `var` 推断）；方法参数和返回值也有类型。建立类型系统的整体认识是学习变量、方法、类的基础。

> 值类型

值类型的特点如下：

- 存储：数据直接存放在变量所属的内存位置
- 复制/赋值：赋值的时候赋值一份值，两个变量各自持有一份数据。修改其中一个数据不会影响到另一个数据

- 常见值类型：int、double、bool、char、decimal、枚举、结构体 (struct) 等。

```
int a = 10;
int b = a; // b 得到的是10的副本
a = 20; // 只改 a. b 仍是 10
```

> 引用类型 

- **存储：** 实际数据在堆上；变量中保存的是**引用**（可理解为“指向对象的地址”）。

- **赋值/复制：** 赋值时复制的是**引用**，两个变量可能指向同一块数据。通过其中一个修改，另一个访问到的也会变化。

- **常见引用类型：** string、类 (class)、数组、接口等。

```c#
int[] arr1 = new int[] { 1, 2, 3 };
int[] arr2 = arr1;    // arr2 和 arr1 指向同一数组
arr1[0] = 99;
```

string类型是引用类型，修改会得到新的字符串，不会修改原内容

> 二者对比																	

| **维度**     | **值类型**        | **引用类型**             |
| ------------ | ----------------- | ------------------------ |
| **存储**     | 数据在变量所在处  | 数据在堆，变量存引用     |
| **赋值语义** | 复制值            | 复制引用（可能共享对象） |
| **常见例子** | int、bool、struct | string、class、数组      |

## 13-变量声明与初始化

声明一个变量的语法如下：

```c#
int count = 0;

double price = 9.99;
```

先声明、后赋值也可以：`int count;` 然后 `count = 0;`。变量名需符合标识符规则，局部变量建议用 camelCase。

> 局部变量

C# 规定：局部变量在使用前必须被明确赋值，否则编译器报错。

```c#
int x;

```

先赋值再使用则合法：`x = 10;` 之后 `Console.WriteLine(x);` 正确。

> var与类型推断

var 表示 “由编译器根据右侧初始化表达式推断类型”。推断完成后，变量类型是确定的，与手写类型等价。

```c#
var count = 10;     // 推断为 int
var name = "Tom";   // 推断为 string
var price = 9.99;   // 推断为 double
```

限制：声明时必须同时初始化；仅适用于局部变量。不能写 `var x;` 再单独赋值。

> 何时使用

- **适合用 `var`：** 右侧类型较长或重复（如泛型）、类型显而易见（如 `var name = "Tom";`），可提高可读性
- **适合用显式类型：** 希望强调类型、或右侧是接口/基类而希望变量类型更明确时

## 14-基础类型

> 类型名：`int`

字面量：直接写数字，如 `0`、`42`、`-100`，不加引号、不带小数点。

```c#
int count = 0;
int age = 18;
```

注意：带小数点的数（如 `3.14`）视为 `double`，不能直接赋给 `int`；需类型转换时

> 类型名：`double`

面量：带小数点的数，如 `3.14`、`0.5`、`-2.5`。

```c#
double price = 9.99;
double rate = 0.85;
```

与 `int` 的区分：有小数点即为浮点（默认 `double`），无小数点即为整数（默认 `int`）。

> 类型名：`bool`

类型名：`bool`。字面量：仅有两个值—— `true` 与 `false`。

```c#
bool isOk = true;
bool flag = false;
```

条件判断（if）与循环（for、while）中的条件表达式结果为 `bool` 类型。

> 类型名：`char`

字面量：用单引号包围的一个字符，如 `'A'`、`'1'`、`'中'`。

> 与 string 的区分（易混点）

| **类型** | **引号** | **内容**       | **示例**               |
| -------- | -------- | -------------- | ---------------------- |
| char     | 单引号   | 恰好一个字符   | `'A'`                  |
| string   | 双引号   | 零个或多个字符 | `""`、`"A"`、`"Hello"` |

注意：`"A"` 是 `string`，不是 `char`；将 `"A"` 赋给 `char` 变量会导致类型不匹配。

```c#
char grade = 'A';
char digit = '9';
```

## 15-c#字符串

>  类型名：`string`。

字面量：用双引号包围的文本，如 `"Hello"`、`"世界"`；空字符串为 `""`。

与 `char` 的区分：

- `char` 为单引号、单字符；`string` 为双引号、可零个或多个字符，故 `"A"` 为 `string`。

> 字符串拼接

在涉及字符串的语境下，`+` 表示拼接，而非数学加法。可将多个字符串连接；也可将字符串与数字等连接，此时数字会先转为字符串再拼接。

```c#
string a = "Hello";
string b = "World";
string c = a + ", " + b;   // "Hello, World"
string msg = "年龄: " + 18; // "年龄: 18"
```

注意：两侧均为数字时 `+` 为数学加法；只要有一侧为 `string`，`+` 即为拼接。

> Length 属性

Length 是 `string` 的属性，表示字符串中字符的个数（字符数，非字节数）。该属性为只读，不可赋值修改。

```c#
string s = "Hello";
int len = s.Length;   // 5
```

空字符串 `""` 的 Length 为 0。后续会常用 Length 做判空或循环边界。

## 16-字符串方法

> string 不可变

在 C# 中，`string` 是不可变的：一旦字符串对象创建，其内容不可被修改。调用 Trim、Replace 等方法时，不会修改原字符串，而是返回一个新的字符串。

若需使用结果，应赋给变量（如 `s = s.Trim();`）或链式调用（如 `s.Trim().Replace("a", "b")`）；原串本身不变。

- 注意：仅写 `s.Trim();` 而不接收返回值，则 `s` 仍带首尾空白。`string` 的方法大多返回新串，要结果须接住返回值。

> Trim 与 Replace

`Trim`：去除字符串首尾空白，中间空白不处理；返回新字符串。 例：`" Hello ".Trim() -> "Hello"`。

```c#
// Tirm 是 去除首尾空格
string A = "   15678315  313456313 13413132 654465132063 646513216546 3465     ";
A = A.Trim();
Console.WriteLine(A);
```

##  17-字符串插值与多变量输出

> 字符串插值语法

在字符串字面量前加 `$`, 在字符串内用 `{ 变量或表达式 }` 嵌入值。大括号内的内容会被求值并转为字符串，再与前后文本拼接。

```c#
string name = "Tom";
int age = 18;
string msg = $"姓名: {name}, 年龄: {age}"; // "姓名: Tom, 年龄: 18"
```

注意：`$` 须紧挨双引号；大括号内写变量或表达式，不写语句。

> 大括号内可以是表达式

`{ }` 内不仅可以写变量名，也可以写表达式（如运算、方法调用）；表达式会先求值再转为字符串嵌入。

```c#
int a = 10, b = 20;
string s = $"{a} + {b} = {a + b}"; // "10 + 20 = 30"
```

## 18-常量与运算顺序

> 常量

字面量是指在代码中直接写出的值，未通过变量或常量名引用的写法。字面量有类型；赋给变量或常量后，变量/常量持有该值。

常见字面量举例：

- **整数**：`0`、`42`、`-100`
- **浮点**：`3.14`、`0.5`
- **布尔**：`true`、`false`
- **字符**：`'A'`；**字符串**：`"Hello"`

**语法：** `const 类型 常量名 = 值;`。声明时必须赋值；赋值后不可再修改。

```c#
const int MaxCount = 100;
const double Pi = 3.14159;
const string AppName = "MyApp";
```

常量适合表示固定不变的值，便于阅读与维护。与变量的区别：**变量可多次赋值，常量只能赋一次。**

> 运算顺序

在表达式中，**乘、除的优先级高于加、减**；**括号可以改变顺序，括号内的先算**。

- `2 + 3 * 4`：先算 `3 * 4` 得 12，再 `2 + 12` 得 **14**

- `(2 + 3) * 4`：先算 `2 + 3` 得 5，再 `5 * 4` 得 **20**

# 第四单元：运算符

## 19-算术运算符

**算术运算符**用于执行基本的数学运算，是编程中最常用的运算符类型。

| **运算符** | **名称** | **示例** | **结果** |
| ---------- | -------- | -------- | -------- |
| +          | 加法     | 5 + 3    | 8        |
| -          | 减法     | 10 - 4   | 6        |
| *          | 乘法     | 3 * 4    | 12       |
| /          | 除法     | 15 / 3   | 5        |
| %          | 取余/模  | 10 % 3   | 1        |

> 加法运算符（+）

基础用法：

```
int a = 5;
int b = 3;
int sum = a + b; // sum = 8

Console.WriteLine(sum); // 输出: 8
```

字符串拼接

```c#
string firstName = "张";
string lastName = "三";
string fullName = firstName + lastName; // "张三"
```

当+的一侧是字符串，另一侧会被转化为字符串

```c#
int age = 25;
string message = "我今年" + age + "岁"; // "我今年25岁"
```

> 减法运算符(-)

基本用法

```c#
int a = 10;
int b = 4;
int difference = a - b; // difference = 6

Console.WriteLine(difference); // 输出: 6
```

负数表示

`-` 也可以作为一元运算符表示负数：

```c#
int negative = -5; // negative = -5
```

> 乘法运算符(*)

基本用法

```c#
int a = 3;
int b = 4;
int product = a * b; // product = 12

Console.WriteLine(product); // 输出: 12
```

实际应用示例

```c#
int price = 25;      // 单价
int quantity = 3;    // 数量
int total = price * quantity; // 总价 = 75
```

> 除法运算符（/）

当两个操作数都是整数时，结果也是整数，且向下取整（截断小数部分）。

```c#
int a = 10;
int b = 3;
int result = a / b; // result = 3 (不是 3.333...)

Console.WriteLine(result); // 输出: 3
```

**注意：** `10 / 3` 在数学中是 `3.333...`，但在整数除法中结果是 `3`（小数部分被丢弃）。

如果至少有一个操作数是浮点数（double 或 float），结果就是浮点数：

```c#
double a = 10.0;
double b = 3.0;
double result = a / b; // result = 3.3333333333333335

Console.WriteLine(result); // 输出: 3.3333333333333335
```

混合类型

```c#
int a = 10;
double b = 3.0;
double result = a / b; // result = 3.3333333333333335（自动提升为 double）
```

> 取余运算符（%）

取余运算符 % 计算两个数相除后的余数。

```c#
int a = 10;
int b = 3;
int remainder = a % b; // remainder = 1 (10 ÷ 3 = 3 余 1)

Console.WriteLine(remainder); // 输出: 1
```

应用方式：

- **判断奇偶性：** `number % 2 == 0` 表示偶数

```c#
    int number = 7;
    if (number % 2 == 0)
    {
        Console.WriteLine("偶数");
    }
    else
    {
        Console.WriteLine("奇数"); // 输出: 奇数
    }
```

- **周期性计算：** 计算星期几、循环索引等

```c#
    int totalMinutes = 125;
    int hours = totalMinutes / 60;   // hours = 2
    int minutes = totalMinutes % 60; // minutes = 5
```

- **提取数字的某一位：** `number % 10` 得到个位数字

```c#
    int number = 1234;
    int lastDigit = number % 10;        // 个位: 4
    int tensDigit = (number / 10) % 10; // 十位: 3
```

> 优先级

从高到低：

1. **括号 `()`：** 最高优先级
2. **乘、除、取余 `\*`、`/`、`%`：** 同级，从左到右
3. **加、减 `+`、`-`：** 同级，从左到右

```c#
int result1 = 2 + 3 * 4;     // 14（先算 3 * 4 = 12，再算 2 + 12 = 14）
int result2 = (2 + 3) * 4;   // 20（先算括号：2 + 3 = 5，再算 5 * 4 = 20）
int result3 = 10 / 2 * 3;    // 15（从 left 到 right：10 / 2 = 5，再算 5 * 3 = 15）
int result4 = 10 % 3 + 5;    // 6（先算 10 % 3 = 1，再算 1 + 5 = 6）
```

## 20-整数除法与余数

当两个操作数都是整数时，结果也是整数，且向下取整（截断小数部分）。

```c#
int a = 10;
int b = 3;
int result = a / b; // result = 3 (不是 3.333...)
```

**整数除法不是四舍五入，而是直接截断（向零方向取整）**

- `10 / 3 = 3`（余数 1 被丢弃）

- `-10 / 3 = -3`（向零方向取整，不是 -4）

> 整数除法的数学含义

整数除法 `a / b` 的结果是：最大的整数 q，使得 q * b <= a.

```c#
int a = 17;
int b = 5;
int quotient = a / b;       // quotient = 3 (17 ÷ 5 = 3 余 2)
int remainder = a % b;      // remainder = 2

// 验证: a = quotient * b + remainder
Console.WriteLine($"{a} = {quotient} * {b} + {remainder}"); // 17 = 3 * 5 + 2
```

负数除法的行为：

```c#
int a = -10;
int b = 3;
int result = a / b; // result = -3 (向零方向取整)
```

**规则**：整数除法的结果向零方向取整，而不是向下取整。


> 整数溢出

当计算结果超出类型的取值范围时，会发生**溢出**（overflow）。

```c#
int max = int.MaxValue;  // 2,147,483,647
int result = max + 1;    // 溢出！结果变成 -2,147,483,648 (最小值)
```

注意：C# 默认情况下不会抛出异常，而是发生环绕（wrap around）。

```c#
int a = int.MaxValue;
Console.WriteLine(a);        // 2,147,483,647
Console.WriteLine(a + 1);    // -2,147,483,648 (溢出到最小值)
```

> 检测溢出异常

可以使用 `checked` 关键字在溢出时抛出异常：

```c#
checked
{
    int max = int.MaxValue;
    int result = max + 1;  // 抛出 OverflowException
}
```

或者使用 `checked` 表达式：

```c#
int max = int.MaxValue;
int result = checked(max + 1);  // 抛出 OverflowException
```

> 如何选择合适的整数类型

选择原则：

1. **默认使用 `int`**：除非有特殊需求，否则使用 `int`（最常用，性能好）
2. **需要更大范围时使用 `long`**：当数值可能超过 `int` 的范围时
3. **节省内存时使用 `short` 或 `byte`**：在数组或集合中存储大量数据时
4. **无符号类型**：当确定数值不会为负数时，可以使用 `uint`、`ulong` 等

```c#
byte age = 25;                       // 年龄：使用 byte 足够
int priceInCents = 9999;             // 价格（分）：使用 int 足够
long fileSize = 5_000_000_000L;     // 文件大小：使用 long
```

> 取余与整数除法的关系

```c#
int a = 17;
int b = 5;

int quotient = a / b;       // 商: 3
int remainder = a % b;      // 余数: 2

// 验证: a = quotient * b + remainder
Console.WriteLine($"{a} = {quotient} * {b} + {remainder}");  // 17 = 3 * 5 + 2
```

取余结果的符号与被除数（左操作数）相同：

```c#
Console.WriteLine(10 % 3);    // 1
Console.WriteLine(-10 % 3);   // -1
Console.WriteLine(10 % -3);   // 1
Console.WriteLine(-10 % -3);  // -1
```

## 21-浮点数类型

C# 提供了三种浮点类型：

| **类型**    | **位数** | **精度**        | **用途** |
| ----------- | -------- | --------------- | -------- |
| **float**   | 32       | 约 7 位小数     | 较少使用 |
| **double**  | 64       | 约 15-17 位小数 | 最常用   |
| **decimal** | 128      | 约 28-29 位小数 | 精确计算 |

默认类型与后缀

- `double` 是 C# 中浮点数的默认类型，`3.14` 会被当作 `double` 类型
- `decimal` 需要显式声明，必须使用 `m` 后缀：`3.14m`
- `float` 需要显式声明，使用 `f` 后缀：`3.14f`

> `double`类型

`double` 是双精度浮点数，占用 64 位（8 字节）内存。

- **范围很大**：可以表示从约 -1.7*10^308 到  1.7*10^308 的数值

- **精度约 15-17 位有效数字**：对于大多数科学计算和工程计算来说，这个精度足够了

- **性能好**：CPU 对 `double` 有硬件支持（FPU），运算速度快

- **有精度损失**：由于是二进制浮点数，某些十进制小数无法精确表示

```c#
double pi = 3.141592653589793;
double height = 175.5;
double temperature = -10.5;
```

> `decimal` 类型

`decimal` 是高精度十进制数，占用 128 位（16 字节）内存。

- **精度高**：可以精确表示约 28-29 位有效数字

- **范围较小**：范围是 正负 1.0 * 10^-28 到 正负 7.9228 * 10^28 ，比 `double` 小很多

- **性能较慢**：没有硬件直接支持，运算速度比 `double` 慢（约 10-100 倍）

- **精确表示十进制小数**：这是它最大的优势，不会出现 0.1+0.2!=0.3 的问题

```c#
decimal price = 99.99m;      // 注意：必须有 m 后缀
decimal amount = 1000.50m;
decimal rate = 0.05m;
```

> 进制浮点数

`double` 是二进制浮点数，这意味着它用二进制来表示小数。但很多十进制小数无法用有限的二进制位精确表示。

```c#
double a = 0.1;
double b = 0.2;
double sum = a + b;
Console.WriteLine(sum == 0.3); // False!
Console.WriteLine(sum);        // 0.30000000000000004
```

**原因**：`0.1` 和 `0.2` 在二进制中是无限循环小数，就像 `1/3` 在十进制中是 `0.333...` 一样。

> decimal 的精确性

`decimal` 是十进制浮点数，它用十进制来表示小数，所以可以精确表示十进制小数。

```c#
decimal a = 0.1m;
decimal b = 0.2m;
decimal sum = a + b;
Console.WriteLine(sum == 0.3m); // True!
Console.WriteLine(sum);         // 0.3
```

这次结果是精确的 `0.3`，没有问题。

金融计算的正确做法：

```c#
// ✅ 正确：金融计算用 decimal
decimal price = 10.00m;
decimal tax = price * 0.08m;  // 8% 税率
decimal total = price + tax;
Console.WriteLine(total);     // 精确输出 10.80
```

> 类型转化

从 double 转换为 decimal：

```c#
double d = 3.14;
decimal m = (decimal)d; // 显式转换
```

**注意**：`double` 转 `decimal` 必须显式转换，因为可能会丢失精度或超出范围。

从 decimal 转换为 double：

```
decimal m = 3.14m;
double d = (double)m; // 显式转换
```

**注意**：`decimal` 转 `double` 也必须显式转换，因为可能会丢失精度。

## 22-比较与逻辑运算符

> 比较运算符

比较运算符用于比较两个值的大小或相等性，返回 `bool` 类型的结果（`true` 或 `false`）。

六种比较运算符：

| **运算符** | **名称** | **示例** | **结果** |
| ---------- | -------- | -------- | -------- |
| **==**     | 等于     | `5 == 3` | false    |
| **!=**     | 不等于   | `5 != 3` | true     |
| **<**      | 小于     | `3 < 5`  | true     |
| **>**      | 大于     | `5 > 3`  | true     |
| **<=**     | 小于等于 | `3 <= 5` | true     |
| **>=**     | 大于等于 | `5 >= 3` | true     |

> 逻辑运算符

逻辑运算符用于组合多个布尔表达式，构建更复杂的条件判断。

| **运算符** | **名称** | **说明**                                   |
| ---------- | -------- | ------------------------------------------ |
| **&&**     | 逻辑与   | 两个条件都为 `true` 时结果为 `true`        |

| **!**      | 逻辑非   | 取反，`true` 变 `false`，`false` 变 `true` |

> 短路求值

逻辑运算符 `&&` 和 `||` 具有短路求值特性：

- **&&**：如果第一个条件为 `false`，不会计算第二个条件，直接返回 `false`
- **||**：如果第一个条件为 `true`，不会计算第二个条件，直接返回 `true`

## 23-if与else

> IF语句

语法格式：

```c#
if (条件表达式)
{
    // 如果条件为 true，执行这里的代码
}
```

- `if` 是关键字，表示「如果」

- `(条件表达式)` 是一个布尔表达式，结果为 `true` 或 `false`

- `{ }` 是代码块，包含条件为 `true` 时要执行的代码

```c#
if (条件表达式)
```

语法说明：

布尔表达式是计算结果为 `true` 或 `false` 的表达式。

常见的布尔表达式：

## 24-多分枝判断

> 多分枝

使用多个`if else`构造的就是多分枝判断语句：

```c#
if (条件1)
{
    // 如果条件1为 true，执行这里的代码
}
else if (条件2)
{
    // 如果条件1为 false 且条件2为 true，执行这里的代码
}
else if (条件3)
{
    // 如果条件1和条件2都为 false 且条件3为 true，执行这里的代码
}
else
{
    // 如果所有条件都为 false，执行这里的代码
}
```

> 嵌套

**嵌套 if** 就是在 `if` 或 `else` 的代码块内部，再使用 `if` 语句。

```c#
if (外层条件)
{
    if (内层条件1)
    {
        // 外层条件为 true 且内层条件1为 true 时执行
    }
    else
    {
        // 外层条件为 true 但内层条件1为 false 时执行
    }
}
else
{
    if (内层条件2)
    {
        // 外层条件为 false 且内层条件2为 true 时执行
    }
}
```

嵌套可以有多层，但一般不建议超过 3 layer（层），否则代码会变得难以理解：

```c#
if (条件1)
{
    if (条件2)
    {
        if (条件3)
        {
            // 三层嵌套
        }
    }
}
```

根据实际需求选择：条件互斥选择分支，条件层级选择嵌套

## 25-switch语句

`switch` 语句是一种多分支选择结构，用于根据一个表达式的值，从多个可能的选项中选择一个执行。

- 根据一个变量的多个固定值进行判断

- 菜单选择、状态判断、枚举值处理等

```c#
// 使用 if-else if (第 24 课学过)
int day = 3;
if (day == 1)
{
    Console.WriteLine("星期一");
}
else if (day == 2)
{
    Console.WriteLine("星期二");
}
else if (day == 3)
{
    Console.WriteLine("星期三");
}

// 使用 switch (更清晰)
int day = 3;
switch (day)
{
    case 1: Console.WriteLine("星期一"); break;
    case 2: Console.WriteLine("星期二"); break;
    case 3: Console.WriteLine("星期三"); break;
}
```

> 基础结构

```c#
switch (表达式)
{
    case 值1:
        // 当表达式等于值1时执行的代码
        break;
    case 值2:
        // 当表达式等于值2时执行的代码
        break;
    case 值3:
        // 当表达式等于值3时执行的代码
        break;
    default:
        // 当所有 case 都不匹配时执行的代码
        break;
}
```

> if与switch的选择

什么时候用 switch：

- 根据一个变量的**多个固定值**进行判断

- 判断的值是**离散的、有限的**（如菜单选项、状态码、枚举值）

- **分支数量较多**（3 个以上）

什么时候用 if-else if：

- 判断条件**不是简单的等值比较**（如范围判断、复杂条件）

- 需要**判断多个变量**或**复杂表达式**

- **分支数量较少**（2-3 个）

## 26-switch简明写法*

**switch 表达式**是 C# 8.0 引入的新特性，它是 switch 语句的表达式版本，可以返回值，语法更简洁。

| **特性**    | **switch 语句**       | **switch 表达式**        |
| ----------- | --------------------- | ------------------------ |
| **返回值**  | 不返回值（执行操作）  | 返回一个值               |
| **语法**    | `case` 标签 + `break` | `值 => 结果`（箭头语法） |
| **break**   | 必须写 `break`        | 不需要 `break`           |
| **default** | `default:`            | `_ => 结果`（弃元模式）  |

基本结构：

```c#
var result = 表达式 switch
{
    值1 => 结果1,
    值2 => 结果2,
    值3 => 结果3,
    _ => 默认结果 // 弃元模式，相当于 default
};
```

- **使用** `表达式 switch` **而不是** `switch (表达式)`

- **使用** `值 => 结果` **的箭头语法，而不是** `case 值:`

- **每个分支用逗号 ，分隔，而不是分号**

- **不需要** `break` **语句**

- **使用** `_ =>` **表示默认分支（弃元模式）**

- **整个表达式必须返回一个值**

```c#
int day = 3;
string dayName;

switch (day)
{
    case 1:
        dayName = "星期一";
        break;
    case 2:
        dayName = "星期二";
        break;
    case 3:
        dayName = "星期三";
        break;
    // ... 篇幅原因省略 4, 5, 6, 7
    default:
        dayName = "未知";
        break;
}

Console.WriteLine(dayName); // 输出: 星期三


Console.WriteLine("---------");
int day2 = 2;

string dayName2 = day2 switch
{
    1 => "星期一",
    2 => "星期二",
    3 => "星期三",
    _ => "未知" // '_' 是弃元模式，等同于 default
};

Console.WriteLine(dayName2); // 输出: 星期三

```

> or模式与关系式表达式

`or` 模式允许你将多个匹配项组合在一起。只要满足其中**任意一个**条件，就会进入该分支。这直接干掉了以前传统 `switch` 里为了实现“或”而写一堆连续 `case` 的臃肿写法。

```c#
int month = 7;

string season = month switch
{
    12 or 1 or 2 => "冬季",
    3 or 4 or 5  => "春季",
    6 or 7 or 8  => "夏季",
    9 or 10 or 11 => "秋季",
    _            => "无效月份"
};

Console.WriteLine(season); // 输出: 夏季
```

`关系模式`允许你直接在分支中使用比较运算符，比如 `<`、`<=`、`>`、`>=`。这在以前的 `switch` 语句中是无法直接实现的（以前必须结合 `when` 关键字）。

```c#
int score = 85;

string grade = score switch
{
    >= 90         => "优秀",
    >= 80 and < 90 => "良好", // 这里结合了 and 模式
    >= 60 and < 80 => "及格",
    < 60          => "不及格",
    _             => "成绩异常"
};

Console.WriteLine(grade); // 输出: 良好
```

> 使用方式

什么时候用 switch 表达式？

- **需要返回一个值**的场景
- **代码逻辑简单**，每个分支只是返回一个值
- 希望代码**更简洁、更现代**

什么时候用 switch 语句？

- **需要执行多个操作**，不只是返回值
- **需要复杂的逻辑**，比如调用多个方法、修改多个变量
- **不需要返回值**，只是根据值执行不同的操作

## 27-FOR循环

> for循环

for循环是一种循环结构，用于在已知循环次数的情况之下重复执行代码块。

- 需要重复执行的单次操作
- 遍历从多的数据结构
- 计数，累积，查找的操作

 基础结构：

```c#
for (初始化; 条件; 迭代)
{
    // 循环体：要重复执行的代码
}
```

- **初始化：** 在循环开始前执行一次，通常用于声明和初始化循环变量

- **条件：** 每次循环前检查，如果为 `true` 则执行循环体，如果为 `false` 则退出循环

- **迭代：** 每次循环体执行完后执行，通常用于更新循环变量

初始化 -> 条件判断 -> [true] -> 执行循环体 -> 迭代 -> 条件判断 -> [true] -> ... [false] -> 退出循环

```c#
for (int i = 1; i <= 10; i++)
{
    Console.WriteLine(i);
}
```

执行流程：

1. **初始化：** `int i = 1`，声明并初始化循环变量 i 为 1
2. **条件判断：** i <= 10 (1 <= 10 为 true)
3. **执行循环体：** 输出 1
4. **迭代：** i++，将 i 增加 1 (i 变为 2)
5. **条件判断：** i <= 10 (2 <= 10 为 true)
6. **... 重复直到 i 变为 11**
7. **条件判断：** i <= 10 (11 <= 10 为 false)
8. **退出循环**

## 28-while与do-while循环

**while 循环**是一种条件循环，只要条件为真（true），就会重复执行循环体内的代码。

```c#
while (条件)
{
    // 循环体：当条件为真时执行的代码
}
```

- 检查条件是否为真

- 如果为真，执行循环体

- 执行完循环体后，再次检查条件

- 重复步骤 2-3，直到条件为假（false）

> do-while循环

**do-while 循环**是一种条件循环，先执行一次循环体，然后检查条件。如果条件为真，继续执行；如果为假，退出循环。（一般来说很少用）

```c#
do
{
    // 循环体：至少执行一次的代码
} while (条件);
```

用一个菜单选择例子解释一下：

```c#
int choice;
do
{
    // 在执行循环的时候会运行
    Console.WriteLine("1. 添加");
    Console.WriteLine("2. 删除");
    Console.WriteLine("3. 退出");
    Console.Write("请选择: ");
    choice = int.Parse(Console.ReadLine());

    if (choice == 1)
        Console.WriteLine("执行添加操作");
    else if (choice == 2)
        Console.WriteLine("执行删除操作");
} while (choice != 3);

Console.WriteLine("程序退出");
```

`do-while`循环会至少循环一次：

```c#
int num;
do
{
    // 生命周期中至少使用一次
    Console.Write("请输入一个正数: "); 
    num = int.Parse(Console.ReadLine());
} while (num <= 0);

Console.WriteLine($"您输入的正数是: {num}");
```

> 区别

| **特性**     | **while 循环**                   | **do-while 循环**                  |
| ------------ | -------------------------------- | ---------------------------------- |
| **执行顺序** | 先判断条件，再执行循环体         | 先执行循环体，再判断条件           |
| **执行次数** | 可能一次都不执行（条件初始为假） | 至少执行一次                       |
| **语法位置** | 条件在循环体之前                 | 条件在循环体之后                   |
| **适用场景** | 不确定是否执行，需要先判断       | 需要至多执行一次，如菜单、输入验证 |

## 29-foreach循环

```c#
foreach (类型 变量名 in 集合)
{
    // 循环体：使用变量名访问当前元素
}
```

- **foreach 关键字后跟括号**

- **括号内：** `类型 变量名` **声明循环变量，** `in` **关键字，然后是集合**

- **循环变量会自动依次获取集合中的每个元素**

- **不需要手动管理索引，不需要检查边界**

- **循环变量是只读的，不能修改集合元素**

> 与`for`循环的对比

```c#
// 使用 for 循环遍历数组
int[] numbers = { 1, 2, 3, 4, 5 };
for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}

// 使用 foreach 循环（更简洁）
int[] numbers = { 1, 2, 3, 4, 5 };
foreach (int num in numbers)
{
    Console.WriteLine(num);
}
```

> `foreach`的基础用法

基本结构：

```c#
foreach (类型 变量名 in 集合)
{
    // 循环体：使用变量名访问当前元素
}
```

- **foreach 关键字后跟括号**

- **括号内：** `类型 变量名` **声明循环变量，** `in` **关键字，然后是集合**

- **循环变量会自动依次获取集合中的每个元素**

- **不需要手动管理索引，不需要检查边界**

- **循环变量是只读的，不能修改集合元素**

> 使用选择

什么时候用 foreach：

- 只需要访问元素，不需要修改元素
- 不需要使用索引
- 希望代码更简洁、更易读
- 遍历集合、数组、字符串等可枚举类型

什么时候用 for：

- 需要修改数组元素
- 需要使用索引（如访问相邻元素）
- 需要倒序遍历或跳过某些元素
- 需要控制循环步长

```c#
// 使用LINQPAD来编译
int[] numbers = { 1, 2, 3, 4, 5 };

foreach (int num in numbers)
{
	num.Dump(); // 代替 Console.WriteLine(num);
}

for (int i = 0; i < numbers.Length; i++)
{
	numbers[i] = numbers[i] * 2; // 修改元素
}

numbers.Dump(); 
```

> 限制

限制 1：不能修改循环变量

```
// ❌ 错误：不能修改循环变量
int[] numbers = { 1, 2, 3 };
foreach (int num in numbers)
{
    num = num * 2; // 编译错误：不能修改只读变量
}

// ✅ 正确：使用 for 循环修改
for (int i = 0; i < numbers.Length; i++)
{
    numbers[i] = numbers[i] * 2; // 可以修改
}
```

限制2：foreach 循环中修改集合可能导致异常

```c#
// ⚠️ 危险：在 foreach 循环中修改集合可能导致异常
List<int> numbers = new List<int> { 1, 2, 3, 4, 5 };
foreach (int num in numbers)
{
    if (num == 3)
        numbers.Remove(num); // 运行时错误：集合在枚举时被修改
}

// ✅ 正确：如果需要修改集合，使用 for 循环（倒序）
for (int i = numbers.Count - 1; i >= 0; i--)
{
    if (numbers[i] == 3)
        numbers.RemoveAt(i);
}
```

限制3：不能倒序遍历

foreach只能从前往后，不能倒叙遍历

## 30-break与continue的使用场景

> break语句

break语句用于立即跳出当前循环，终止循环的执行

```c#
for (int i = 0; i < 10; i++)
{
    if (某个条件)
        break; // 跳出循环
    // 其他代码
}
// break 后, 程序继续执行这里
```

执行流程：

1. 循环正常执行
2. 遇到 `break` 语句
3. 立即跳出循环，不再执行循环体内的后续代码
4. 继续执行循环后的代码

适用场景：

- 找到目标后立即停止搜索
- 满足退出条件时提前结束循环
- 错误发生时终止处理

> continue语句

执行流程：

1. 循环正常执行
2. 遇到 `continue` 语句
3. 跳过本次循环的剩余代码
4. 继续下一次循环（更新循环变量，检查条件）

适用场景：

- 跳过某些不需要处理的元素
- 过滤掉不符合条件的数据
- 遇到错误时跳过当前项，继续处理下一个

# 第六单元：类与对象

## 33-类简介，什么是类

我们用生活中的例子来理解类和对象。

想象一下，我们生活有很多**汽车**。虽然每辆汽车都不一样，但它们都有共同的特征：

- 都有品牌、颜色、型号
- 都能启动、加速、刹车
- 都有四个轮子、一个方向盘

>  类和关系的对象

在编程中，我们可以定义一个**汽车类 (Car)**，来描述所有汽车的共同特征。然后，我们可以根据这个类创建多个**汽车对象**，比如：

- 一辆红色的宝马
- 一辆蓝色的奔驰
- 一辆黑色的奥迪

**类 (Class)** 就像是一个**模板或蓝图**，定义了对象的共同特征和行为。

**对象 (Object)** 是根据类创建出来的**具体实例**，每个对象都有自己的具体值。

> 类的例子：Student

我们用一个更具体的例子来理解类和对象。

假设我们要管理学生信息，我们可以定义一个 **Student 类**，下面用表格表示：

| **类别**                        | **成员名称 (中文/英文)** | **数据类型 / 作用**            | **说明**                                |
| ------------------------------- | ------------------------ | ------------------------------ | --------------------------------------- |
| **属性** *(Data / Properties)*  | 姓名 (`Name`)            | 字符串 (`string`)              | 存储学生的具体名字，如“张三”            |
|                                 | 年龄 (`Age`)             | 整数 (`int`)                   | 存储学生的年龄，如 `18`                 |
|                                 | 学号 (`StudentId`)       | 字符串 (`string`)              | 存储唯一的学生编号，如 `"001"`          |
|                                 | 成绩 (`Score`)           | 浮点数/整数 (`double` / `int`) | 存储学生的分数，如 `90`                 |
| ---                             | ---                      | ---                            | ---                                     |
| **方法** *(Behavior / Methods)* | 学习 (`Study`)           | 无返回值 (`void`)              | 模拟学生学习的行为，可输出“XX正在学习”  |
|                                 | 考试 (`TakeExam`)        | 无返回值 或 返回分数           | 模拟学生考试的行为，可更新 `Score` 属性 |
|                                 | 显示信息 (`ShowInfo`)    | 无返回值 (`void`)              | 打印该学生对象当前的所有属性信息        |

然后，我们可以根据这个类创建多个学生对象：

- **学生1**：张三，18岁，学号001，成绩90分
- **学生2**：李四，19岁，学号002，成绩85分
- **学生3**：王五，20岁，学号003，成绩95分

每个学生对象都有自己的姓名、年龄、学号、成绩，但都遵循 Student 类的定义。这就是类和对象的关系。

> 面向对象编程的核心概念

面向对象编程有三个核心概念：

| **核心概念 (Concept)**      | **核心定义与机制**                                           | **主要作用与优势**                                           | **经典示例**                                                 |
| --------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **1. 封装** (Encapsulation) | 把相关的属性（数据）和操作（方法）封装在一起，形成一个不可分割的整体。 | 内部数据和方法受到保护，外部不能直接访问，必须通过类提供的公共接口进行访问。提高了系统的**安全性和内聚性**。 | 外部无法直接修改类内部的私有变量，需要通过 `get` 和 `set` 方法进行间接访问。 |
| **2. 继承** (Inheritance)   | 一个类（子类）可以继承另一个类（父类）的特征、属性和行为。   | 子类可以直接复用父类的代码，减少重复开发；同时还可以在子类中添加自己特有的新功能，极具**扩展性**。 | 比如：`Car`（汽车）类可以继承 `Vehicle`（交通工具）类，直接获得其“排量”、“行驶”等基本属性和方法。 |
| **3. 多态** (Polymorphism)  | 同一个方法或接口，在不同的对象实例上执行时可以有不同的行为表现。 | 增强了程序的**灵活性和通用性**，实现了“一个接口，多种实现”，让系统更易于后续升级和维护。 | 比如：`Animal` 类有一个 `MakeSound` 方法，在 `Dog` 对象上调用时叫“汪汪”，在 `Cat` 对象上调用时叫“喵喵”。 |

> 类的组成部分

| **组成部分**                  | **核心定义与机制 **                                          | **经典示例**                                                 | **补充：常见访问修饰符**                        | **底层逻辑与作用**                                           |
| ----------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ----------------------------------------------- | ------------------------------------------------------------ |
| **1. 字段** (Field)           | • 用来**存储数据**。 • 字段是类的**数据成员**。              | 比如 `Car` 类的 `color`、`brand`、`speed`。                  | 通常为 **私有 (`private`)**                     | 用于在类内部保存对象的状态，通常不直接暴露给外部，以实现数据安全（封装）。 |
| **2. 属性** (Property)        | • 用来**访问和设置字段的值**，提供更好的封装。 • 可以获取和设置颜色。 | 比如 `Car` 类的 `Color` 属性。                               | 通常为 **公开 (`public`)**                      | 包含 `get` 和 `set` 访问器。它就像字段的“看门人”，可以在赋值或读取时加入逻辑验证（例如：限制车速不能为负数）。 |
| **3. 方法** (Method)          | • 用来**定义类的行为**。 • 方法是类的**功能成员**。          | 比如 `Car` 类的 `Start`（启动）、`Accelerate`（加速）、`Brake`（刹车）。 | 通常为 **公开 (`public`)** 或保护 (`protected`) | 代表对象“能做什么”。它是包含一系列语句的代码块，通过调用方法来执行特定的操作或计算。 |
| **4. 构造函数** (Constructor) | • 用来**初始化对象**，创建对象时**自动调用**。               | 比如 `Car` 类的构造函数，可以设置初始颜色、品牌等。          | 通常为 **公开 (`public`)**                      | 一种特殊的方法，**没有返回值类型**，且**函数名必须与类名完全一致**。用于在 `new` 一个新对象时为其分配内存并赋予初始值。 |

## 36-属性

属性：通过 `get` / `set` 访问器控制字段的读写。

| **特性**     | **字段 (Field)** | **属性 (Property)**         |
| ------------ | ---------------- | --------------------------- |
| **定义方式** | 类型 字段名;     | 类型 属性名 `{ get; set; }` |
| **访问控制** | 直接访问         | 通过访问器控制              |
| **数据验证** | 无法验证         | 可以在 `set` 中验证         |
| **额外逻辑** | 无法添加         | 可以在访问器中添加          |
| **命名规范** | camelCase        | PascalCase                  |

> 属性的定义

```c#
class Car
{
    private string color; // 私有字段

    // 属性
    public string Color
    {
        get { return color; }    // get 访问器：读取值
        set { color = value; }   // set 访问器：设置值
    }
}
```

- 属性名 PascalCase (Color、Speed)
- `get` 用 `return` 返回值，`set` 用 `value` 接传入值
- 属性常 `public`，背后字段常 `private`

> 属性的使用

用法与字段相同：赋值走 set，读取走 get。

```c#
Car car1 = new Car();
car1.Color = "红色";           // 调用 set 访问器
string c = car1.Color;         // 调用 get 访问器
Console.WriteLine(car1.Color); // 输出：红色
```

- 赋值时自动调用 set 访问器
- 读取时自动调用 get 访问器
- 使用方式与字段相同，但功能更强大

> 只读属性，只写属性

只有 get，没有 set：

```c#
class Car
{
    private string id;

    public string Id
    {
        get { return id; } // 只有 get，没有 set
    }

    public Car(string id)
    {
        this.id = id; // 只能在构造函数中设置
    }
}
```

只有 set，没有 get (少见)：

```c#
class Car
{
    private string password;

    public string Password
    {
        set { password = value; } // 只有 set，没有 get
    }
}
```

> 带验证的属性

使用`set`添加`if-else`语句筛选数据

```c#
class Car
{
    private int speed;

    public int Speed
    {
        get { return speed; }
        set
        {
            if (value < 0) // 验证速度不能为负数
            {
                speed = 0;
            }
            else if (value > 200) // 验证速度不能超过 200
            {
                speed = 200;
            }
            else
            {
                speed = value;
            }
        }
    }
}
```

## 38-方法重载

方法重载是指在同一个类中，允许存在多个方法名相同、但参数列表（类型、个数或顺序）不同的方法。

- **方法名相同；参数列表不同**（数量、类型或顺序）
- **返回值、访问修饰符可不同，不参与重载区分**

**签名 = 方法名 + 参数列表（不含返回类型）**。签名不同才能重载。

```c#
class Calculator
{
    // 重载：两个 int 参数
    public int Add(int a, int b)
    {
        return a + b;
    }

    // 重载：三个 int 参数
    public int Add(int a, int b, int c)
    {
        return a + b + c;
    }

    // 重载：两个 double 参数
    public double Add(double a, double b)
    {
        return a + b;
    }
}
```

## 39-构造函数

构造函数 (Constructor)：创建对象时自动调用，用于**初始化对象**。

构造函数的特点

- **方法名与类名相同：**构造函数的名称必须与类名完全相同
- **没有返回值**：构造函数不返回任何值，连 `void` 都不写
- **自动调用**：创建对象时自动调用，不需要手动调用
- **初始化对象**：用来设置对象的初始状态

**构造函数与普通方法的区别**

| **特性**     | **构造函数**              | **普通方法**      |
| ------------ | ------------------------- | ----------------- |
| **方法名**   | 必须与类名相同            | 可以任意命名      |
| **返回值**   | 没有返回值（不写 `void`） | 有返回值或 `void` |
| **调用时机** | 创建对象时自动调用        | 需要手动调用      |
| **作用**     | 初始化对象                | 执行特定操作      |

## 40-this关键字

在编写代码的过程中，形式参数可能与类字段产生冲突，这个时候引入了`this`关键字：

```c#
public class Student
{
	private string name;
	private int age;

	public Student(string name, int age)
	{
		// 赋值给类字段 - 通过构造函数方法
		// 使用this来表示当前对象的字段
		this.name = name;
		this.age = age;
	}
}
```

**this** 关键字是一个引用，指向当前对象实例。在类的实例方法或构造函数中，可以使用 **this** 来引用当前对象。

| **分类**     | **核心要点**         | **详细说明 / 应用场景**                                      |
| ------------ | -------------------- | ------------------------------------------------------------ |
| **特点**     | **指向当前对象**     | 代表当前正在操作的那个特定的类**实例**。                     |
|              | **解决命名冲突**     | 当方法的参数名（或局部变量）与类的字段名同名时，用 `this` 区分。 |
|              | **可选性**           | 如果没有同名冲突，可以省略 `this`，编译器会自动识别并关联。  |
|              | **仅限实例成员**     | 只能在实例方法或构造函数中使用，**不能**在 `static`（静态）方法中使用。 |
| ---          | ---                  | ---                                                          |
| **主要用途** | **区分字段和参数**   | 明确指定某变量是类的字段，而非同名的参数。例如：`this.name = name;` |
|              | **调用其他构造函数** | 在一个构造函数中通过 `this(...)` 调用同类的另一个构造函数，减少重复代码。 |
|              | **返回当前对象**     | 在方法最后执行 `return this;`，可以实现优雅的**链式调用**（如 `stu.SetAge(20).PrintInfo();`）。 |

## 41-显示命令行参数*

> 命令行参数

对一个Main函数添加一个`arg`数组，可以使这个Main可以接受一些参数。这些参数概念上类似于命令行中的一些参数

```cmd
ipconfig -all;
```

如上举例，`-`之后的`all`就是命令行参数的一种，添加了`all`之后`ipconfig`会出现更多的详细细节，也就是添加参数类似于在函数中输入变量输出一些特定的返回值，这类参数的特点如下：

- **外部输入**：在程序运行时由用户提供，而不是在代码中硬编码

- **字符串数组**：多个参数之间用空格分隔，每个参数是一个字符串

- **灵活配置**：可以让同一个程序在不同参数下执行不同的操作

- **常见用途**：文件路径、配置选项、操作模式等

> Main的签名

```c#
static void Main(string[] args)
{
    // 使用 args 数组访问命令行参数
}
```

- **string[] args**：字符串数组，包含所有命令行参数

- **args[0]**：第一个参数

- **args[1]**：第二个参数

- **args.Length**：参数的数量

**如果没有参数**：args 为空数组，args.Length 为 0

# 第七单元：面向对象进阶

## 43-封装与访问修饰符

**封装 (Encapsulation)** 是面向对象编程的核心原则之一，指的是将数据（字段）和操作数据的方法（方法）组合在一起，并控制对数据的访问。

封装的目的：

- **数据保护：** 防止外部代码直接访问和修改内部数据

- **接口设计：** 通过公开的方法和属性提供统一的访问接口

- **代码维护：** 内部实现可以改变，而不影响外部代码

- **数据验证：** 在访问数据时可以进行验证和处理

封装就像汽车的仪表盘：你不需要知道发动机如何工作，只需要通过方向盘、油门、刹车等接口来控制汽车。内部实现被封装起来，外部只能通过**公开的接口**进行操作。

> 访问修饰符

**访问修饰符 (Access Modifiers)** 用于控制类成员（字段、属性、方法等）的访问级别，决定哪些代码可以访问这些成员。

常用的访问修饰符：

| **访问修饰符** | **说明** | **访问范围**           |
| -------------- | -------- | ---------------------- |
| public         | 公共的   | 任何地方都可以访问     |
| private        | 私有的   | 只能在同一个类内部访问 |

> public 访问修饰符

`public` 表示**公共的**，使用 `public` 修饰的成员可以在任何地方访问，包括类的外部。

```c#
class Student
{
    // public 字段：任何地方都可以访问
    public string name;
    public int age;

    // public 方法：任何地方都可以调用
    public void ShowInfo()
    {
        Console.WriteLine($"姓名: {name}, 年龄: {age}");
    }
}
```

- **访问范围最广：** 任何地方都可以访问

- **通常用于：** 属性、公开的方法、构造函数

- **注意：** `public` 字段虽然可以访问，但不推荐直接使用 `public` 字段

> private 访问修饰符

`private` 表示**私有的**，使用 `private` 修饰的成员只能在同一个类内部访问，类的外部无法访问。

- **访问范围最小：** 只能在类内部访问
- **通常用于：** 私有字段、内部辅助方法
- **作用：** 保护数据，防止外部直接访问

> 封装的最佳实践

推荐的做法

1. **字段私有化：** 使用 `private` 修饰字段
2. **属性公开化：** 使用 `public` 修饰属性
3. **方法按需公开：** 需要外部调用的方法使用 `public`，内部辅助方法使用 `private`
4. **构造函数公开：** 通常使用 `public` 修饰构造函数

```c#
class Student
{
    // 1. private 字段
    private string name;
    private int age;

    // 2. public 属性
    public string Name { get; set; }
    public int Age { get; set; }

    // 3. public 构造函数
    public Student(string name, int age)
    {
        this.name = name;
        this.age = age;
    }

    // 4. public 方法 (需要外部调用)
    public void ShowInfo() { }

    // 5. private 方法 (内部辅助方法)
    private void Validate() { }
}
```

## 46-protected 和 internal 访问修饰符

> protected 访问修饰符

`protected` 表示**受保护的**，成员可以在当前类及其派生类（子类）中访问。

protected 的特点：

- **当前类可以访问：** 在定义 `protected` 成员的类内部可以访问
- **派生类可以访问：** 继承该类的子类可以访问 `protected` 成员
- **外部不能访问：** 类的外部不能直接访问 `protected` 成员

protected 的使用场景：

- 希望成员在派生类中可用，但对外部隐藏
- 为继承设计，允许子类访问父类的成员
- 实现封装的同时支持继承

```c#
class Animal
{
	protected string name; // protected 字段

	public Animal(string name)
	{
		this.name = name;
	}

	protected void MakeSound() // protected 方法
	{
		Console.WriteLine($"{name} 发出声音");
	}

	public void ShowInfo()
	{
		Console.WriteLine($"动物名称: {name}");
		MakeSound(); // 当前类可以访问 protected 成员
	}
}

class Dog : Animal
{
	public Dog(string name) : base(name) { }

	public void Bark()
	{
		MakeSound(); // 派生类可以访问 protected 成员
		Console.WriteLine($"{name} 在叫"); // 派生类可以访问 protected 字段
	}
}

void Main()
{
	Animal chara = new Animal("xixi");
	// chara.MakeSound(); 无法使用 - 只有派生类可以调用这个方法
	
	
	Dog dog = new Dog("多多");
	dog.Bark();
	
}
```

> internal 访问修饰符*

`internal` 表示**内部的**，成员可以在当前程序集 (Assembly) 内访问。

internal 的特点

- **程序集内可访问：** 同一个程序集（项目）内的代码可以访问
- **程序集外不可访问：** 其他程序集（项目）不能访问
- **默认访问级别：** 类、结构体等类型的默认访问级别是 `internal`

internal 的使用场景

- 希望成员在项目内可用，但对其他项目隐藏
- 实现项目内部的封装，避免外部项目访问
- 控制 API 的可见性，只暴露必要的 `public` 成员

> 访问修饰符级别

| **访问修饰符**         | **当前类** | **派生类** | **同一程序集** | **其他程序集** | **说明**           |
| ---------------------- | ---------- | ---------- | -------------- | -------------- | ------------------ |
| **public**             | ✓          | ✓          | ✓              | ✓              | 任何地方都可以访问 |
| **protected internal** | ✓          | ✓          | ✓              | X              | 当前程序集或派生类 |
| **protected**          | ✓          | ✓          | X              | X              | 当前类和派生类     |
| **internal**           | ✓          | X          | ✓              | X              | 当前程序集内       |
| **private**            | ✓          | X          | X              |                |                    |

## 47-继承与基类 base关键字

**继承 (Inheritance)** 是面向对象编程的核心特性之一，允许一个类（派生类）继承另一个类（基类）的成员（字段、属性、方法等），从而可以重用基类的代码，并在此基础上扩展新功能。

继承的术语：

| **术语**                   | **说明**                     | **示例**     |
| -------------------------- | ---------------------------- | ------------ |
| **基类 (Base Class)**      | 被继承的类，也称为父类或超类 | Animal       |
| **派生类 (Derived Class)** | 继承基类的类，也称为子类     | Dog、Cat     |
| **继承关系**               | 派生类与基类之间的关系       | Dog : Animal |

> 继承的实现

使用冒号 (`:`) 实现继承：

```c#
// 基类
class Animal
{
    public string Name { get; set; }
    public int Age { get; set; }

    public void Eat()
    {
        Console.WriteLine($"{Name}正在吃东西");
    }
}

// 派生类：继承自 Animal
class Dog : Animal
{
    public void Bark()
    {
        Console.WriteLine($"{Name}在汪汪叫");
    }
}
```

语法要点

- **冒号 (`:`)**：用于指定继承关系
- **派生类继承基类的所有成员**：字段、属性、方法等（受访问修饰符限制）
- **派生类可以添加新成员**：在继承的基础上扩展功能
- **派生类可以访问基类的 `public` 和 `protected` 成员**：但不能访问 `private` 成员

> Base关键字*

`base` 关键字用于在派生类中访问基类的成员，包括：

- 调用基类的构造函数
- 调用基类的方法
- 访问基类的属性

```c#
// 基类
class Animal
{
    public string Name { get; set; }
    public int Age { get; set; }

    public Animal(string name, int age)
    {
        Name = name;
        Age = age;
        
        Console.WriteLine($"创建动物: {name}, 年龄: {age}");
    }
}

// 派生类
class Dog : Animal
{
    public string Breed { get; set; }

    // 使用 base 关键字调用基类构造函数
    public Dog(string name, int age, string breed) : base(name, age)
    {
        Breed = breed;
        
        Console.WriteLine($"品种: {breed}");
    }
}
```

base 的使用场景：

- **调用基类构造函数**：当基类有带参构造函数时，必须在派生类构造函数中使用 `base` 调用
- **调用基类方法**：当需要调用基类的原始实现时使用
