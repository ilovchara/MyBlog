# 第七章：面向对象进阶

## 51-接口与多态

多态（Polymorphism）是指同一个接口可以有不同的实现方式，同一个方法调用可以有不同的行为。

而接口是一个规定实现类的规范，接口中的字段以及方法都必须要在实现它的类中实现。

> 使用接口实现多态

只需要实现接口，也就是使用`:`在要实现接口的类之后加上接口即可。与继承的语法相似。

之后在实现接口的类中，可以自定义对应的字段还有方法的逻辑。

```c#
// 定义接口
interface IShape
{
	double GetArea();
	double GetPerimeter();
}

// 实现类：圆形
class Circle : IShape
{
	private double radius;

	public Circle(double radius)
	{
		this.radius = radius;
	}

	public double GetArea()
	{
		return Math.PI * radius * radius;
	}

	public double GetPerimeter()
	{
		return 2 * Math.PI * radius;
	}
}

// 实现类：长方形
class Rectangle : IShape
{
	private double width;
	private double height;

	public Rectangle(double width, double height)
	{
		this.width = width;
		this.height = height;
	}

	public double GetArea()
	{
		return width * height;
	}

	// 注：第三张图片中长方形的 GetPerimeter() 方法被截断了，
	// 这里按照逻辑为您补全：
	public double GetPerimeter()
	{
		return 2 * (width + height);
	}
}
```

> 多接口实现

一个类可以实现多个接口，从而同时具有多种行为。

```c#
class ClassName : IInterface1, IInterface2, IInterface3
{
    // 实现所有接口的成员
}
```

多接口实现的优势

- **灵活性：** 一个类可以同时具有多种行为
- **解耦合：** 接口之间相互独立，互不影响
- **可组合性：** 可以根据需要组合不同的接口
- **符合单一职责原则：** 每个接口定义一种职责

```c#
// ===== 定义多个接口 =====

interface IFlyable
{
    void Fly();
}

interface ISwimmable
{
    void Swim();
}

interface IWalkable
{
    void Walk();
}

// ===== 实现多个接口 =====

class Duck : IFlyable, ISwimmable, IWalkable
{
    public void Fly()
    {
        Console.WriteLine("鸭子飞");
    }

    public void Swim()
    {
        Console.WriteLine("鸭子游泳");
    }

    public void Walk()
    {
        Console.WriteLine("鸭子走路");
    }
}
```

> 接口的应用场景

1.解耦合

下列代码中实现了依赖注入，不再需要在本类中创建一个其它类的对象造成耦合。只需要使用一个接口对象从外界接收对象即可。

```c#
// 定义接口
interface IDataRepository
{
    void Save(string data);
    string Load();
}

// 实现接口
class FileRepository : IDataRepository { /* ... */ }
class DatabaseRepository : IDataRepository { /* ... */ }

// 使用接口，不依赖具体实现
class DataService
{
    private IDataRepository repository;

    // 通过构造函数注入具体的仓储实现
    public DataService(IDataRepository repository)
    {
        this.repository = repository;
    }

    public void ProcessData(string data)
    {
        repository.Save(data);
    }
}
```

2.插件系统

```c#
// 定义插件接口
interface IPlugin
{
    string Name { get; }
    void Execute();
}

// 实现不同的插件
class LoggingPlugin : IPlugin { /* ... */ }
class ValidationPlugin : IPlugin { /* ... */ }

// 插件管理器
class PluginManager
{
    private List<IPlugin> plugins = new List<IPlugin>();

    public void AddPlugin(IPlugin plugin)
    {
        plugins.Add(plugin);
    }

    public void ExecuteAll()
    {
        foreach (IPlugin plugin in plugins)
        {
            plugin.Execute();
        }
    }
}
```

> 接口与多态特性

| **特性**     | **接口**           | **抽象类**                 |
| ------------ | ------------------ | -------------------------- |
| **多重继承** | 支持多重实现       | 只支持单继承               |
| **成员**     | 只能包含签名       | 可以包含实现               |
| **字段**     | 不能包含字段       | 可以包含字段               |
| **使用场景** | 定义契约、实现多态 | 提供通用实现、代码复用     |
| **灵活性**   | 更灵活，易于扩展   | 提供默认实现，减少重复代码 |

## 52-密封sealed与override

> 密封类的实例

密封类（Sealed Class）是使用 `sealed` 关键字修饰的类，**不能被其他类继承**。

密封类的特点

- **不能被继承：** 密封类不能作为基类，不能被其他类继承
- **可以实例化：** 密封类可以正常创建对象，只是不能被继承
- **可以继承其他类：** 密封类可以继承其他非密封类
- **可以包含虚方法：** 密封类可以包含虚方法，但虚方法不能被重写

密封类的作用

- **防止继承：** 防止类被进一步继承，保护类的设计
- **性能优化：** 编译器可以对密封类进行优化，提高性能
- **设计意图：** 明确表示类不应该被继承，表达设计意图

```c#
void Main()
{
	StringHelper SH = new StringHelper();
	string str = "chara";

}

sealed class StringHelper
{
	public static string Reverse(string str)
	{
		char[] chars = str.ToCharArray();
		Array.Reverse(chars);
		return new string(chars);
	}

	public static string ToUpperFirst(string str)
	{
		if (string.IsNullOrEmpty(str))
			return str;
		return char.ToUpper(str[0]) + str.Substring(1);
	}
}

// 密封类无法继承
// class chara : StringHelper
```

> 密封方法

密封方法（Sealed Method）是使用 `sealed` 关键字修饰的 `override` 方法，**防止该方法在派生类中被进一步重写**。

密封方法的特点

- **必须是 override：** 密封方法必须是重写的方法，不能是普通方法
- **防止进一步重写：** 密封方法不能被派生类进一步重写
- **只能在重写方法上使用：** `sealed` 关键字只能用于 `override` 方法

密封方法的作用

- **限制重写：** 防止方法在继承链中被进一步重写
- **保护实现：** 保护方法的实现，防止被修改
- **设计意图：** 明确表示方法不应该被进一步重写

```c#
class BaseClass
{
    public virtual void Method()
    {
        Console.WriteLine("基类方法");
    }
}

class DerivedClass : BaseClass
{
    public sealed override void Method()
    {
        Console.WriteLine("派生类方法");
    }
}

// 错误：不能重写密封方法
class FurtherDerivedClass : DerivedClass
{
    public override void Method() // // 编译错误
    {
        Console.WriteLine("进一步派生类方法");
    }
}
```

> 密封类的特性

密封类一般适用于：

- 工具类、辅助类

- 不希望被继承的类

- 性能优化的类

特性如下：

| **特性**     | **密封类**     | **密封方法**               |
| ------------ | -------------- | -------------------------- |
| **关键字**   | `sealed class` | `sealed override`          |
| **作用对象** | 整个类         | 单个方法                   |
| **限制**     | 类不能被继承   | 方法不能被进一步重写       |
| **使用场景** | 工具类、最终类 | 保护方法实现               |
| **继承关系** | 不能作为基类   | 类可以继承，但方法不能重写 |

# 第八章：结构体，枚举，记录与元组

## 55-结构体

**结构体 (`struct`)** 是一种值类型，用于封装一组相关的数据。

| **维度** | **核心内容**        | **详细说明 / 应用场景**                          |
| -------- | ------------------- | ------------------------------------------------ |
| **定义** | **结构体 (struct)** | 一种值类型，用于封装一组相关的数据。             |
| **特点** | **值类型**          | 存储在栈上（或作为对象的一部分）。               |
|          | **值语义**          | 赋值时复制的是**值**，而不是引用。               |
|          | **轻量级**          | 适合存储小型的数据结构。                         |
|          | **性能优势**        | 能够避免堆分配，从而减少垃圾回收（GC）的压力。   |
| **用途** | **简单数据结构**    | 适合用来表示坐标点、颜色、日期范围等。           |
|          | **需值语义场景**    | 适合用于数学向量、矩阵等需要独立复制的场景。     |
|          | **性能优化场景**    | 适用于需要避免堆分配、对性能要求极高的底层场景。 |

结构体的语法要点

| **语法维度**     | **规则与限制**             | **说明**                                                   |
| ---------------- | -------------------------- | ---------------------------------------------------------- |
| **关键字**       | `struct`                   | 使用 `struct` 关键字来定义结构体。                         |
| **组成要素**     | 字段、属性、方法、构造函数 | 结构体内部可以包含这些常见的类成员。                       |
| **无参构造函数** | **有限制允许**             | 传统上结构体不能包含无参构造函数，但 **C# 10+ 开始支持**。 |
| **继承性**       | **不支持**                 | 结构体**不能**继承其他类，也**不能**继承其他结构体。       |
| **接口实现**     | **支持**                   | 结构体**可以**实现一个或多个接口。                         |

```c#
struct StructName
{
    // 字段
    public int Field1;
    public string Field2;

    // 属性
    public int Property1 { get; set; }

    // 方法
    public void Method1()
    {
        // 方法实现
    }

    // 构造函数
    public StructName(int field1, string field2)
    {
        Field1 = field1;
        Field2 = field2;
    }
}
```

> 结构体 (struct) 与 类 (class) 的核心区别

| **特性**         | **结构体 (struct)**                | **类 (class)**     |
| ---------------- | ---------------------------------- | ------------------ |
| **类型**         | **值类型**                         | **引用类型**       |
| **存储位置**     | **栈上**（或作为对象的一部分）     | **堆上**           |
| **赋值语义**     | **复制值**                         | **复制引用**       |
| **默认值**       | 所有字段为默认值（`0`、`null` 等） | `null`             |
| **继承**         | **不能继承**                       | **可以继承**       |
| **无参构造函数** | C# 10+ 可以定义                    | 可以定义           |
| **适用场景**     | 小型数据结构、值语义               | 复杂对象、引用语义 |

> 赋值

结构体是值类型，传输结构体的数据是传输一个值。

类是引用类型，传输类的数据是传递一个引用。

```c#
struct PointStruct
{
    public int X { get; set; }
    public int Y { get; set; }
}

PointStruct p1 = new PointStruct { X = 10, Y = 20 };
PointStruct p2 = p1;  // 复制值
p2.X = 100;           // 修改 p2，p1 不会改变
Console.WriteLine(p1.X);  // 输出：10
```

> 修改结构体

如果需要在方法中修改结构体，可以使用 `ref` 或 `out`：

- 使用 ref 参数(传入并修改)

```c#
void Main()
{
	// 1. 初始化结构体实例，变量名改用 point 避免和局部函数的参数 p 冲突
	PointStruct point = new PointStruct { X = 10, Y = 20 };

	// 2. 传入引用
	ModifyPoint(ref point);

	Console.WriteLine(point.X); // 成功输出: 999

	// 局部函数定义
	void ModifyPoint(ref PointStruct p)
	{
		p.X = 999;
	}
}

// 3. 在 Main 方法外部定义这个结构体
public struct PointStruct
{
	public int X { get; set; }
	public int Y { get; set; }
}
```

- 使用 out 参数(传出并返回)

```c#
void Main()
{
    PointStruct p;
    CreatePoint(out p);
    
    // LINQPad 中除了 Console.WriteLine，更推荐用方便的 .Dump() 
    p.X.Dump(); // 或者写成 Console.WriteLine(p.X);
}

// 1. 将方法定义在 Main 之外
void CreatePoint(out PointStruct p)
{
    p = new PointStruct { X = 100, Y = 200 };
}

// 2. 将结构体定义在最外层
public struct PointStruct
{
    public int X { get; set; }
    public int Y { get; set; }
}
```

| **特性**                 | **ref 参数**                         | **out 参数**                                 |
| ------------------------ | ------------------------------------ | -------------------------------------------- |
| **核心目的**             | 传入一个值，在方法内**修改**它。     | 让方法拥有**多个返回值**（传出数据）。       |
| **调用前是否需要初始化** | **是**（必须赋初值，否则编译报错）。 | **否**（传个空变量进去即可）。               |
| **方法内部是否必须赋值** | **否**（方法内不改它也没关系）。     | **是**（方法结束前必须赋值，否则编译报错）。 |
| **方法内能否读取初始值** | **能**（因为进来前已经有值了）。     | **不能**（在方法内首次赋值前，不能读取它）。 |

## 56-记录类型 record*

记录类型（record）是 C# 9 引入的新特性，用于表示不可变数据。

| **核心特点**     | **详细说明描述**                                             | **技术实现 / 关键点**                               |
| ---------------- | ------------------------------------------------------------ | --------------------------------------------------- |
| **值相等性**     | 基于属性和字段的值来比较两个对象是否相等，而非常规类的引用地址比较。 | 只要对象的所有属性值相同，`Equals()` 即返回 `true`  |
| **不可变性**     | 记录类型默认是不可变的，数据在初始化后不能被修改，确保线程安全与数据稳定。 | 默认使用 `init` 访问器代替 `set` 访问器             |
| **简洁语法**     | 提供了极为精简的声明方式，可以通过单行代码直接定义包含属性和构造函数的类。 | 支持位置记录 (`Positional Record`) 语法声明         |
| **自动生成成员** | 编译器在后台自动为记录类型生成常用样板代码，显著减少开发者手动编写的工作量。 | 自动重写 `Equals`、`GetHashCode`、`ToString` 等方法 |
| **with 表达式**  | 支持通过非破坏性突变来创建新记录，即复制原对象并同时修改其中指定的某些属性值。 | 使用 `myRecord with { Property = newValue }` 语法   |

典型应用场景：

| **典型用途 / 场景**        | **适用场景说明**                                             | **带来的核心优势**                               |
| -------------------------- | ------------------------------------------------------------ | ------------------------------------------------ |
| **表示不可变数据**         | 适用于系统配置信息、只读应用程序状态以及领域驱动设计 (DDD) 中的值对象。 | 防止多线程环境下的数据竞态与意外篡改             |
| **需要值相等性的业务场景** | 例如在缓存对比、数据库记录行比较、消息队列中的数据校验等需要直接比对内容的场景。 | 免去手动重写复杂相等性比较逻辑的烦恼             |
| **简化数据传输对象定义**   | 在 Web API、微服务间通信或层级架构间传递的 DTO (Data Transfer Object)。 | 用单行代码代替臃肿的类结构，大幅度提升代码可读性 |

> 声明

```c#
record Person(string Name, int Age);

void Main()
{
    Person p1 = new Person("张三", 25);
    Person p2 = new Person("张三", 25);
    
    Console.WriteLine(p1 == p2);   // 输出：True
    Console.WriteLine(p1);         // 输出：Person { Name = 张三, Age = 25 }
}
```

> 记录类型的相等

值相等性 vs 引用相等性

| **特性**        | **类 (class)**     | **记录类型 (record)** |
| --------------- | ------------------ | --------------------- |
| **相等性**      | 引用相等性（默认） | 值相等性（默认）      |
| **比较方式**    | 比较引用地址       | 比较属性值            |
| **Equals 方法** | 需要手动实现       | 自动生成              |
| **GetHashCode** | 需要手动实现       | 自动生成              |

```c#
record Person(string Name, int Age);

Person p1 = new Person("张三", 25);
Person p2 = new Person("张三", 25);
Person p3 = p1;

Console.WriteLine(p1 == p2);              // True (值相等)
Console.WriteLine(p1 == p3);              // True (引用相等)
Console.WriteLine(ReferenceEquals(p1, p2)); // False (不是同一个对象)
```

- init 访问器

记录类型的属性使用 `init` 访问器，表示**只能在初始化时设置**：

```c#
{

}

Person p = new Person { Name = "张三", Age = 25 };
// p.Name = "李四"; // 编译错误：init 访问器只能在初始化时设置
```

## 57- record class 和 record struct*

> record class: 引用类型记录

在 C# 9 中，`record` 关键字默认表示 `record class`：

```c#
// 以下两种写法等价
record Person(string Name, int Age);
record class Person(string Name, int Age);
```

**引用类型**：存储在堆上

**引用语义**：变量存储的是引用

**可以为 null**：可以赋值为 null

**值相等性**：基于属性值比较相等性

```c#
record class Person(string Name, int Age);

Person? p1 = new Person("张三", 25);
Person? p2 = null;
Person? p3 = new Person("张三", 25);

Console.WriteLine(p1 == p3); // True (值相等性)
Console.WriteLine(p1 == p2); // False
```

> record struct: 值类型记录

使用 `record struct` 关键字定义值类型记录：

```c#
record struct Point(int X, int Y);
```

**值类型**：存储在栈上（或作为对象的一部分）

**值语义**：赋值时复制值

**不能为 null**：值类型不能为 null（除非使用可空类型 `Point?`）

**值相等性**：基于属性值比较相等性

**性能优势**：避免堆分配，减少 GC 压力

```c#
record struct Point(int X, int Y);

Point p1 = new Point(10, 20);
Point p2 = new Point(10, 20);
Point p3 = p1; // 复制值

Console.WriteLine(p1 == p2); // True (值相等性)
Console.WriteLine(p1 == p3); // True (值相等性)
p3 = new Point(30, 40);
Console.WriteLine(p1.X);    // 10 (p1 未改变)
```

> `record class` vs `record struct`

| **特性**        | **record class**    | **record struct**          |
| --------------- | ------------------- | -------------------------- |
| **类型**        | 引用类型            | 值类型                     |
| **存储位置**    | 堆上                | 栈上（或作为对象的一部分） |
| **赋值语义**    | 复制引用            | 复制值                     |
| **可以为 null** | 可以（默认）        | 不可以（除非使用可空类型） |
| **性能**        | 堆分配，有 GC 压力  | 栈分配，无 GC 压力         |
| **相等性**      | 值相等性            | 值相等性                   |
| **适用场景**    | 大型数据、需要 null | 小型数据、性能要求高       |

## 58-枚举enum的定义

枚举 (enum) 是一种值类型，用于定义一组命名常量。

- **类型安全：** 只能使用枚举中定义的值

- **代码可读性：** 使用有意义的名称，而不是数字

- **固定值集合：** 表示一组相关的常量

- **底层类型：** 默认是 `int`，可以指定其他整数类型

> 枚举的定义

使用 enum 关键字定义枚举：

```
enum EnumName
{
    Value1,
    Value2,
    Value3
}
```

枚举成员使用 `PascalCase` 命名

枚举成员默认从 0 开始，依次递增

可以指定枚举成员的显式值

可以指定枚举的底层类型

> 枚举的函数

- ToString 方法

将枚举实例转换为其对应的**字符串名称**。

```
DayOfWeek day = DayOfWeek.Monday;
Console.WriteLine(day.ToString()); // 输出: Monday
```

- Parse 方法

将一个**字符串**（或数字的字符串形式）转换为对应的**枚举实例**。

```
string dayStr = "Monday";
DayOfWeek day = Enum.Parse(dayStr);
Console.WriteLine(day); // 输出: Monday
```

- TryParse 方法

**安全地**将字符串转换为枚举实例。

```
string dayStr = "Monday";
if (Enum.TryParse(dayStr, out DayOfWeek day))
{
    Console.WriteLine(day); // 输出: Monday
}
else
{
    Console.WriteLine("解析失败");
}
```

- GetValues 方法

获取指定枚举中**所有常量值的数组**。

```
foreach (DayOfWeek day in Enum.GetValues())
{
    Console.WriteLine(day);
}
```

> 常量 (const) 与 枚举 (enum) 的对比

| **特性**       | **常量 (const)**     | **枚举 (enum)**      |
| -------------- | -------------------- | -------------------- |
| **类型安全**   | 否（可以使用任何值） | 是（只能使用枚举值） |
| **代码可读性** | 较低                 | 较高                 |
| **值集合**     | 独立常量             | 有组织的集合         |
| **IDE 支持**   | 有限                 | 完整（自动补全）     |
| **适用场景**   | 单个常量值           | 固定值集合           |

## 59-元组*

**元组（Tuple）** 是一种数据结构，用于将多个值组合在一起。

元组的特点

- **多值组合**：可以将多个不同类型的值组合在一起
- **轻量级**：不需要定义类或结构体
- **简洁语法**：使用元组字面量语法，代码简洁
- **解构支持**：可以轻松解构元组获取各个值

> 元组的定义

使用元组字面量语法定义元组：

方式一：元组字面量

```c#
var tuple = (10, "Hello", true);
(int, string, bool) tuple2 = (10, "Hello", true);
```

![image-20260611163255148](./6-9-.NET%E5%9F%BA%E7%A1%80%E4%B8%8B/image-20260611163255148.png)

方式二：命名元组

```
var tuple = (Number: 10, Message: "Hello", IsActive: true);
(int Number, string Message, bool IsActive) tuple2 = (10, "Hello", true);
```

![image-20260611163548570](./6-9-.NET%E5%9F%BA%E7%A1%80%E4%B8%8B/image-20260611163548570.png)

语法要点

- 使用圆括号 `()` 定义元组
- 元组成员用逗号分隔
- 可以指定成员名称（命名元组）
- 可以使用 `var` 进行类型推断

> 示例

示例一：未命名元组

```c#
var tuple = (10, "Hello", true);
(int, string, bool) tuple2 = (10, "Hello", true);

Console.WriteLine(tuple.Item1); // 10
Console.WriteLine(tuple.Item2); // Hello
Console.WriteLine(tuple.Item3); // True
```

![image-20260611163838475](./6-9-.NET%E5%9F%BA%E7%A1%80%E4%B8%8B/image-20260611163838475.png)

示例二：命名元组

```c#
var tuple = (Number: 10, Message: "Hello", IsActive: true);
(int Number, string Message, bool IsActive) tuple2 = (10, "Hello", true);

Console.WriteLine(tuple.Number);   // 10
Console.WriteLine(tuple.Message);  // Hello
Console.WriteLine(tuple.IsActive); // True

// 可以看到，命名元组使用有意义的名称访问成员，代码更清晰。
```

![image-20260611164121244](./6-9-.NET%E5%9F%BA%E7%A1%80%E4%B8%8B/image-20260611164121244.png)

> 访问

访问未命名元组

```
var tuple = (10, "Hello", true);

Console.WriteLine(tuple.Item1); // 10
Console.WriteLine(tuple.Item2); // Hello
Console.WriteLine(tuple.Item3); // True
```

访问命名元组

```c#
var tuple = (Number: 10, Message: "Hello", IsActive: true);

Console.WriteLine(tuple.Number);   // 10
Console.WriteLine(tuple.Message);  // Hello
Console.WriteLine(tuple.IsActive); // True

// 也可以使用 Item1、Item2、Item3
Console.WriteLine(tuple.Item1); // 10
```

> 解构

解构是将元组的各个成员分别赋值给不同的变量。一般有三种方式

```c#
var tuple = (Number: 10, Message: "Hello", IsActive: true);

// 方式一：使用 var
var (number, message, isActive) = tuple;

// 方式二：指定类型
(int number, string message, bool isActive) = tuple;

// 方式三：使用现有变量
int number;
string message;
bool isActive;
(number, message, isActive) = tuple;
```

解构示例

```c#
var tuple = (10, "Hello", true);
var (num, msg, active) = tuple;

Console.WriteLine(num);    // 10
Console.WriteLine(msg);    // Hello
Console.WriteLine(active); // True
```

![image-20260611165537648](./6-9-.NET%E5%9F%BA%E7%A1%80%E4%B8%8B/image-20260611165537648.png)

方法返回元组

```c#
(int Sum, int Product) Calculate(int a, int b)
{
    int sum = a + b;
    int product = a * b;
    return (sum, product);
}

var result = Calculate(10, 20);
Console.WriteLine($"和: {result.Sum}, 积: {result.Product}");
```

解构返回值

```c#
(int Sum, int Product) Calculate(int a, int b)
{
    return (a + b, a * b);
}

var (sum, product) = Calculate(10, 20);
Console.WriteLine($"和: {sum}, 积: {product}");
```

> 元组 vs 其它方式

**简单多返回值**：使用元组

**复杂数据结构**：使用类或结构体

**需要复用**：使用类或结构体

**临时组合**：使用元组

| **方式**      | **优点**         | **缺点**                       |
| ------------- | ---------------- | ------------------------------ |
| **out 参数**  | 简单直接         | 需要预先声明变量，代码不够优雅 |
| **类/结构体** | 类型明确，可复用 | 需要定义类型，代码量大         |
| **元组**      | 简洁，支持解构   | 不适合复杂数据结构             |
